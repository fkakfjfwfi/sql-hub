💡 前辈们的避坑要点

Key Takeaways

全部提炼自上面这些高赞帖与面经，条条都是前人用面试教训换来的。

① 分清「书写顺序」和「执行顺序」

写是 SELECT…FROM…WHERE…GROUP BY…HAVING…ORDER BY…LIMIT，执行却是 FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT。理解了它，别名报错、WHERE 里不能用聚合等问题都会豁然开朗。知乎高赞详解 →

② 窗口函数是面试分水岭

rank / dense_rank / row_number 的并列区别、lag / lead 做连续登录、ntile 切分层级——多名面经作者强调「窗口函数非常重要，有些面试官会专门问」。看真实面经 →

③ 别只看视频，动手才是关键

多个回答的共同结论：视频/书籍 3 天 + 刷题 4 天，一周即可入门；「最重要的不是看，而是亲手敲」。每学一个语法立刻去 SQLZoo / 牛客找对应题目。

④ 客户端工具选免费的就够

Navicat Premium Lite 已官方免费；DBeaver 是 GitHub 高星开源；预算充足可上 DataGrip。MySQL 8.x 社区版作为学习环境完全够用。

⑤ 牛客 + LeetCode 双刷策略

牛客 SQL 篇（employees 库 82 题）覆盖校招笔试绝大多数题型；学有余力再刷 LeetCode 数据库题看耗时排名，双刷完「基本没有 SQL 题能难到你」。

⑥ 大数据岗要多答一层「引擎」

面试被问 Hive 时，常追问数据倾斜原因与优化、MapJoin 参数、分区裁剪等。SQL 会写只是及格线，懂执行引擎才是加分项（见上方大数据方向专区）。

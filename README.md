- 在线访问：`https://<你的用户名>.github.io/sql-hub/`
- 数据采集自 B站 / 知乎 / 小红书 / GitHub / 牛客 等平台（2026-10-25），所有链接可点击直达原文。

## 功能

- 六阶段学习路线（进度自动保存在浏览器本地）
- 全局搜索 + 标签筛选（入门 / 刷题 / 进阶 / 面试 / 大数据 / 免费）
- 54 个精选资源，全部单文件实现，无任何外部依赖

## 更新方法

编辑 `index.html` 后：

```bash
git add index.html
git commit -m "update resources"
git push
```

GitHub Pages 会自动重新发布（约 1 分钟生效）。
